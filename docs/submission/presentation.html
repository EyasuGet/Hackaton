The Challenge

Structural Barriers in East African Tech Education

Four Critical Inequities Facing Regional Learners

📶 1. Bandwidth Constraints

Mobile data (Ethio Telecom / Safaricom) is costly, high-latency, and prone to dropouts. Continuous video streaming and heavy AI chats fail under 3G networks.

🗣 2. Linguistic Isolation

Technical curricula are overwhelmingly English-only. Learners need concepts explained in Amharic (አማርኛ) with Ge'ez script and Dual Ethiopic/Gregorian calendars.

♿ 3. Assistive Tech Inequity

Visually impaired learners using screen readers (NVDA, TalkBack) face broken tab sequences, missing ARIA live alerts, untrapped modals, and unreadable code widgets.

⏳ 4. Synchronous Bottleneck

Live office hours require constant online connectivity. Learners need reliable asynchronous human help escalation that preserves context across disconnections.

Architecture & Engineering

Clean Architecture & Zero-Secret Deployment

Ports & Adapters, Unprivileged Containers, and Strict Network Isolation

⚙ Fastify API Core

Node.js 22-alpine runtime running as unprivileged user node (uid 1000). Schema-validated endpoints and Clean Architecture domain rules.

⚛ React 19 / Vite SPA

High-performance frontend with zero heavy CSS framework overhead. Accessible semantic HTML, fast initial bundle load (<100KB gzipped).

🛡 Caddy & PostgreSQL

Caddy reverse proxy with automatic ACME HTTPS, HSTS, and strict CSP. PostgreSQL 18 isolated to internal_net with zero host ports exposed.

Zero-Secret Hygiene: .env.example with empty placeholders, parameterized Compose manifests, and automatic token stripping from proxy access logs.

Core Journey 1/3

Grounded Tutoring & Offline Resilience

Strict Citations, Dual Calendars & Curated FAQ Caching

📖 Strict Lesson Grounding

Answers are grounded strictly in approved course lesson units (e.g. Future of VA Industry). Every claim includes an accessible citation link. Out-of-scope questions trigger truthful refusal and human help.

📅 Dual Ethiopic Calendar

Displays deadlines and session scheduling in both Ethiopian Calendar (e.g. ኅዳር 6 ቀን 2017 ዓ.ም.) and Gregorian, synchronized to Addis Ababa Time (EAT, UTC+3).

⚡ Offline FAQ Cache

PWA Service Worker caches approved public FAQ units. When disconnected, an accessible offline badge appears. Truthful behavior: answers FAQs locally without claiming live cloud reachability.

Core Journey 2/3

Consented Voice & Asynchronous Help

Review-Before-Send Audio & Atomic Support Queue

🎙 Review-Before-Send Voice

Microphone capture activates only on explicit user click. Transcribed Amharic or English text is presented in an editable text box for inspection before submission. Audio is immediately purged.

🔊 Dual Speech Playback

Zero-cost native Web Speech API with accessible speed slider (0.75x–1.5x) plus optional cloud TTS adapter. Full text transcript remains on screen for complete sound-off parity.

📬 Asynchronous Support Queue

Learners submit support requests with context quote preview and privacy disclosure. Atomic database claims prevent duplicate staff handling. Persistent inbox retains replies across reboots.

Core Journey 3/3

Controlled Screen Sharing & Career Tools

WebRTC Peer Collaboration & Private Accommodations

🖥 Desktop Screen Sharing

WebRTC peer stream initiated strictly by learner gesture. Displays a persistent red 'Stop Sharing' control. Coturn TURN relay bypasses restrictive CGNAT firewalls.

📱 Graceful Mobile Fallback

Detects mobile browsers lacking getDisplayMedia and automatically provides an accessible one-click bridge to asynchronous text help with pre-filled context.

💼 Career Q&A & Accommodations

Sourced job vacancy Q&A with live links. Confidential interview accommodation composer visible only to learner and coordinator; zero medical diagnosis required (7-day TTL).

Interface text audit, 2026-11-15 (accommodation.intro, accommodation.descriptionPrompt in messages.ts); T3-025-A Addressed
No captions or sign language Everything spoken is also text: replies stay on screen during read-aloud, and voice questions become editable text before they are sent. The product has no video that needs captions. Sign-language interpretation is not provided. Conformance report, 1.2.1 Partly — sign language is outside Track 3 scope
Help English-only The help request, help inbox and accommodation flows have Amharic interface text; a test fails if any dictionary entry lacks Amharic. Afaan Oromo, Tigrinya, Somali and Arabic are in progress (T3-046). i18n.test.tsx Addressed for Amharic; other languages in progress

SMS job alerts reach phones without a browser. External job boards themselves are not changed. T3-025-A, T3-021-B Addressed in our product; external boards out of scope
